# 跨进程恢复验收

此入口验证当前生产下载、任务快照和清理路径在进程中断后的行为，仅操作本机随机端口 fixture 与临时文件。它不是安装升级、真实系统休眠或突然断电验收；不运行已发布 GUI，不访问个人配置或系统凭据库。

## 运行

使用 README 中已安装 Paramiko 的 Python 环境。先构建当前库测试程序：

```powershell
cargo test --locked --offline --manifest-path src-tauri/Cargo.toml --lib --no-run
```

将 Cargo 打印的 `Executable` 路径传入启动器（路径必须位于本项目 `src-tauri/target` 下）：

```powershell
tests/.runtime-fixture-py312/Scripts/python.exe tests/process_recovery.py --binary "<测试程序绝对路径>"
```

空间有限时可只移除应用测试目标的调试符号，依赖缓存与断言保持不变：`cargo rustc --locked --offline --manifest-path src-tauri/Cargo.toml --lib --profile test -- -C debuginfo=0 -C strip=debuginfo`。需要本机测试清单时按 README 设置 `TERMRILL_TEST_MANIFEST=1`，运行结束恢复原环境值。新测试入口在普通回归中不启动子进程；只有启动器明确设置阶段变量时才运行。

## 四项验收

| 场景       | 通过条件                                                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 强退后续传 | 真实接收至少 512 KiB 后强制结束独立测试进程；新进程加载任务清单、重新验证主机与认证，完成 8 MiB 下载，长度和 SHA256 与源一致；完成后任务清单为空 |
| 强退后移除 | 新进程通过生产清理入口移除本任务临时内容与任务记录，已有正式目标内容不变                                                                         |
| 源变化保护 | 强退后修改本机 fixture 的源内容；新进程因续传前缀不匹配失败，保留正式目标、临时内容和任务记录                                                    |
| 断线恢复   | 接收正文后发出连接关闭信号，等待错误路径收尾；新进程重新认证后完成下载，长度与 SHA256 一致                                                       |

启动器拥有所有子进程；准备最多 30 秒、恢复最多 60 秒，超时结束本次进程树。每项使用独立临时目录，结束后核对根目录和命名再清理本次密钥与数据。失败仅保留有界本机日志，成功报告只含固定场景、布尔值与字节数；结果位于 ignored 的 `tests/.runtime-process-recovery-results/`，不得提交运行数据。

当前用例使用单条数据连接以稳定复现连续前缀；不能由此宣称多连接乱序写入、系统休眠、断电或发布包的全部强退组合已经验收。
