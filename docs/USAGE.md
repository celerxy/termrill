# TermRill 使用指南

更新：2026-10-23。本文描述当前实现；平台和服务器验收状态见 [功能矩阵](SUPPORT_MATRIX.md) 与 [验收记录](READINESS.md)。

## 连接与会话

填写目标服务器地址、端口、用户名和认证方式；需要标准 SSH 跳板时单独填写跳板信息。目标和跳板分别确认 SHA256 主机指纹，首次连接和指纹变化不能跳过确认。厂商专用堡垒机的网页审批、菜单或专用协议不等同于标准跳板，当前不承诺支持。

密码、私钥和交互认证按服务器能力使用。验证码或多轮提示选择交互认证，每轮最多等待 120 秒，最多 16 轮；回答不进入凭据库。保存密码需主动选择，系统服务不可用时返回错误，不使用明文替代。macOS Keychain / Linux Secret Service 代码已接入，但对应平台尚未独立验收；Linux 需要桌面 D-Bus、Secret Service 及已解锁的凭据库。

点击侧栏配置可打开或切换会话；右键“在新标签中连接”可建立同配置的独立会话。切换标签保留后台传输和终端，关闭已连接标签前确认停止该会话操作。标签和已认证连接不跨应用重启恢复，未完成传输记录可在重新认证后恢复。

## 文件管理与布局

本地/远程支持目录收藏、最近访问及成功导航的前进/后退。远程记录按配置 ID、目标和跳板身份隔离。收藏、最近目录与布局保存在本机，不做云同步；路径历史只保留当前工作区。

文件列表分页并虚拟滚动：远程每页最多 256 项，本地每页最多 1000 项；名称搜索在分页前执行，可找到未浏览的条目。只搜索当前目录，不递归搜索正文；深页和稀疏搜索仍需扫描，跨页枚举遇到并发增删时可能漏项或重复，应刷新核对。

双面板和终端区域可拖动调整，支持键盘调整及恢复默认。命令面板调用现有界面操作，不执行任意 Shell，也不接管终端和编辑器中的常规输入。

批量重命名针对 2～100 个普通文件，先预览名称及冲突，再逐项执行；失败或取消不回滚已经确认成功的改名。远程权限支持 rwx 和 UID/GID；递归批量操作跳过链接与特殊文件，不递归修改根目录，最多深度 128、100000 项。已完成修改不自动回滚，ACL 和本地批量权限修改未提供。

## 传输、覆盖与恢复

文件先写入目标目录的 `.termrill-*.part`，完成核对及同步后安装到正式路径。同名覆盖需要明确选择；失败时尝试恢复旧目标，无法恢复时显示保留的备份位置。SFTP 检查与重命名不是所有服务器上的原子事务，大小和修改时间不能识别所有并发改写，应避免同时修改传输源。

暂停保留临时内容。取消清理当前临时文件，但不会撤销目录任务中已经完成的文件或已创建目录。失败、断开或退出保留续传内容；重连后重新认证，并核对临时文件前缀和已完成文件摘要，不自动放宽覆盖权限。

未连接时，“连接后续传”只恢复选中的任务；取消认证、取消指纹确认或更换端点都会清除本次恢复意图。有其他未结束任务时，恢复入口禁止重连，避免中断其他操作。没有后台自动重连。

普通下载在等待 READ 时按连接统计 DATA 正文；持续约 30 秒无数据会隔离该数据连接，将未完成范围转交本次租约中已验证且仍可用的连接，不新增认证或自动重连。全部数据连接失效时任务报错并保留连续续传前缀。消费/写盘导致读取长时间未轮询时不累计为网络停收；持续有部分正文到达也不算停收。此检测不用于上传、预览或归档操作。

TUN/VPN 由系统接管普通 TCP 流量，应用内多条连接仍可能共用代理出口。下载按一批响应调整读取窗口，整个租约的所有下载文件共享最多 32 MiB 在途正文预算，写盘队列和摘要缓存另计；这些措施不代表代理线路或服务器带宽已经验收。

多连接上传在全部写入/关闭确认及源核对通过后，先恢复稳定的续传临时名；后续安装失败会保留完整内容，重试仍逐字节核对前缀。恢复临时名本身失败时不会主动删除已写完的独立暂存文件，错误会列出待核对路径；这种独立暂存文件不会自动作为续传来源。权限已一致时不重复设置；需要变更权限但失败时仍拒绝安装。若提示目标已安装、仅旧备份清理失败，应先刷新核对文件与备份，不直接重复上传。

移除任务会先清理该任务拥有的临时文件，上传清理需要连接原服务器。清理失败时保留记录供重试；正式文件、目录、其他任务的临时文件及回滚备份保留。

上传新文件默认权限 `0644`、新目录 `0755`，覆盖保留原文件权限位。并发、单任务限速和辅助连接受设置及服务器能力限制，不保证跑满带宽。符号链接传输复制链接本身，不跟随其目标；Windows 与远端之间仅支持可验证的相对链接，Windows 创建链接需要相应权限。目录联接及其他 reparse point、特殊文件不支持传输。

## 文本、表格与文档预览

文本编辑上限 2 MiB，保存保留识别的原编码；无法无损编码或原文件摘要变化时拒绝覆盖。支持 UTF-8、UTF-16、GBK/GB18030、Big5、Shift_JIS 等编码，自动识别是启发式，短文本可能误判。分段只读预览可手动切换编码，不改变后续保存参数。

超过 64 KiB 的远程文本优先分段显示，首批最多 8 KiB、后续最多 32 KiB；查找范围是已加载内容。2 MiB 以内可显式加载全文编辑，关闭、读完或源变化时释放 reader；未加载正文不能当作完整文件保存。

CSV/TSV 可切换表格与原始文本，表格不执行公式或 HTML。支持引号内换行、双引号和分隔符，每页 100 条；最多 8388608 个 UTF-16 代码单元、10001 条逻辑记录（含表头）、256 列。过滤仅覆盖已解析内容。

Markdown 支持语法高亮、KaTeX 和 Mermaid；公式使用不信任模式，图表使用严格模式，失败保留源码。Notebook 只展示已有代码和输出，不执行单元、不启动内核，不渲染主动 HTML、JavaScript 或交互式 widget。Notebook 沿用文本全文入口的 2 MiB 限制。

图片、PDF 和 EPUB 预览上限 32 MiB，完整读取后显示，读取可取消；文件签名必须匹配支持类型。远程预览使用独占数据连接，PDF 翻页和搜索、EPUB 章节切换访问已加载的本机数据，不再逐页请求服务器。大文件的首次等待和内存占用仍受完整读取影响。

### EPUB 阅读器

在本地或远程文件面板打开 `.epub`，也可预览归档中的 EPUB 条目。支持 EPUB 2 的 NCX 目录、EPUB 3 的导航目录、章节切换与书内链接、14–32px 字号和 PNG/JPEG/GIF/WebP 书内图片。目录标题单行显示，可通过细滚动条、触控板、Shift＋滚轮或目录标题右侧的左右按钮横向查看。拖动目录右边缘可调整宽度，也可聚焦分隔线后按方向键调整，Home 或双击恢复默认宽度；隐藏再显示保留本次目录宽度和滚动位置。当前目标只高亮一行，同一章内的不同小节分别定位。没有目录时按书中阅读顺序列出章节。

只读重排正文，不执行脚本、加载外部资源或采用原书 CSS、字体、音视频及固定版式；不支持 DRM、声明加密或字体混淆的书籍。正文需为有效 UTF-8 XHTML；SVG 章节与 SVG 图片暂不支持。不保存阅读位置或书籍内容。

容器最多 4096 项，单资源最多 8 MiB，总展开大小最多 64 MiB；损坏、加密、越界路径或超限会明确报错。关闭后丢弃过期解析结果并释放图片内存 URL，解码不写入磁盘。浏览器回归使用虚构内容和模拟 IPC：运行 `npx vite --config tests/showcase-ui.vite.ts`，打开 `http://127.0.0.1:15422/tests/epub-ui.html`。此入口不代表真实服务器验收。

### PDF 阅读器

- 连续滚动、页码跳转、文字选择、全文搜索及半透明命中高亮；缩略图、页面与目录按可见窗口渲染。
- 目录为紧凑单行列表，长标题可横向滚动；支持多级折叠、全部展开/折叠、标题搜索及当前章节高亮。
- 拖动侧栏边缘调整宽度，方向键调整、Home 或双击恢复默认；隐藏再打开保留本次侧栏状态和滚动位置。
- 支持 25%～300% 缩放、适应宽度/整页、旋转和阅读区全屏；控件合并到最底部状态栏，窄窗口可横向滚动。全屏交互仍需桌面环境验收。
- 按 PDF 指纹在本机记录最近 50 份文档的页码和缩放，不保存文件名、服务器路径或正文；不恢复旋转和页内精确偏移，清除 WebView 数据会清除记录。
- Worker、字体、CMap 和 WASM 解码器随包发布，JPEG 2000/JBIG2 使用本地 WASM。没有 OCR、批注编辑或加密 PDF 密码输入入口，扫描图片没有文字层时不能搜索。

当前连接只在内存中缓存最近一份不超过 16 MiB 的完整 PDF，重新打开仍检查源属性；来源变化、断开或缓存条件不成立时重新读取。搜索最多保留 10000 个命中，文本页缓存最多 32 页、约 4 MiB。交互回归见 [PDF 阅读器回归](PDF_READER_REGRESSION.md)。

## 归档

| 格式                                   | 读取、预览、校验、解压 | 创建与修改         | 密码能力                     |
| -------------------------------------- | ---------------------- | ------------------ | ---------------------------- |
| ZIP                                    | 支持                   | 支持创建及增删     | AES-256 内容加密，文件名可见 |
| 7Z                                     | 支持                   | 支持，增删完整重建 | AES-256 内容及文件名加密     |
| TAR / TAR.GZ / TAR.BZ2 / TAR.XZ 及别名 | 支持                   | 支持，增删完整重建 | 不支持密码                   |
| RAR                                    | 支持既有受支持格式     | 不支持             | 读取受支持密码包             |
| 单文件 GZ / BZ2 / XZ                   | 支持                   | 不支持             | 不支持密码                   |

客户端执行压缩，不要求远端安装压缩工具。创建/重建非 ZIP 格式使用有界内存中间包，生成归档最多 512 MiB、10000 项、单文件最多 256 MiB；非 ZIP 展开内容与中间包也各有 512 MiB 上限，内存峰值可能高于最终文件。不是无限流式打包。7Z 使用有限字典和单线程，固实包读取可能需顺序展开。

ZIP 随机预览读取中央目录和条目范围；索引最多 16 MiB、10000 项，条目预览最多 32 MiB。多格式转换的容量限制不能套用为所有 ZIP 操作的统一限制。TAR/7Z 重建保留内容和目录结构，元数据标准化，不保留 ACL、扩展属性、所有者或链接。分卷包不支持。

错误密码、旧版本摘要、不安全路径、链接、大小写冲突、膨胀超限或取消都不能继续安装。覆盖仍需确认；多文件解压不是整体事务，取消时已完成条目可能保留。密码只在当前面板内存中使用，不写入配置或报告。第三方文本见 [许可说明](THIRD_PARTY_NOTICES.md)。

## 单向目录同步

规则记录绝对目录、方向、比较方式和排除项，加载规则不会自动执行。每个连接身份最多 20 条规则、最多 100 个连接范围；端点或认证身份变化后隔离规则。

严格模式对同大小普通文件核对 SHA256；快速模式只比较大小及秒级修改时间，相同元数据不能证明内容相同。排除项最多 32 条、每条 256 字节，支持区分大小写的 `*`、`?`、`**`；不允许绝对路径和 `..`。比较、同步均可取消，覆盖仍需确认，默认保留目标独有文件。

双方都存在的普通文本可只读对照，每端最多 2 MiB、合计最多 6000 行。任务结果报告仅当前会话保留，清单最多显示前 1000 项，不把未逐文件确认的结果标为成功。双向合并、删除镜像和定时同步未实现。

## 终端与服务器工作台

每工作区最多四个终端，支持标签、分屏、搜索和展开。搜索快捷键 Ctrl/Cmd+F，Enter/Shift+Enter 切换命中，Esc 收起并返回终端。终端握手失败只关闭该通道，不绕过服务器限制，文件功能仍可用。

服务器状态默认关闭，仅 Linux CPU、内存和根分区空间可主动开启，CPU 从第二次采样显示；请求完成后间隔五秒，同连接至少间隔五秒，全局最多三个工作台请求。不是所有挂载点或长期监控图表。

常用命令最多 50 条、每条 8 KiB，先预览目标及内容，再确认执行；无 PTY、无交互输入，执行最多 15 秒、输出最多 64 KiB。超时关闭独立通道，不能保证远端进程已停止，结果未知时不自动重试。

配置交换 JSON 最多 1 MiB、200 个连接，先预览再以新 ID 追加；同名不覆盖，也不自动连接。导出仅包含白名单连接元数据、私钥路径及分组，不包含密码、私钥内容或主机信任。新设备需重新核对私钥路径和首次主机指纹。

## 诊断

错误提示提供分类与脱敏摘要，摘要不包含地址、完整路径、文件正文或凭据。完整原始错误只在当前界面显示，不自动上传；尚未统一所有弹窗的错误入口。

性能日志位于应用日志目录的 `performance.log`，超过 4 MiB 轮转为 `performance.previous.log`，最多两份。记录阶段、数量与耗时，不记录完整路径、主机地址、密码或正文。性能日志用于定位等待，不代表带宽或真实服务器性能承诺。
