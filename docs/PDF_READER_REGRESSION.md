# PDF 阅读器回归

本机独立回归入口，不连接真实服务器，不读取用户 PDF。使用生产侧栏、布局及阅读记录 Hook；隔离模式以占位块代替正文，真实样本模式使用本机生成的 50 页 PDF 及生产 `PdfPreview`。

## 执行

```powershell
node --test tests/pdf-reader.test.mjs tests/pdf-navigation.test.mjs
npx vite --config tests/pdf-reader-ui.vite.ts
```

浏览器打开 `http://127.0.0.1:15421/tests/pdf-reader-ui.html`。此端口仅用于测试，不改变应用开发端口；结束后按 Ctrl+C 关闭。测试进度仅保存在此浏览器测试来源的 localStorage。

## 交互步骤与预期

| 场景           | 操作                                      | 预期                                                 |
| -------------- | ----------------------------------------- | ---------------------------------------------------- |
| 长标题及空标题 | 切到目录，横向滚动                        | 行高 26px，不换行；空标题显示“未命名章节”            |
| 多级搜索       | 输入 `LLM?`                               | 显示命中及两级父目录；清空后恢复折叠状态             |
| 搜索空结果     | 输入不存在的标题                          | 显示明确空结果提示                                   |
| 折叠           | 点击全部折叠，再全部展开                  | 子项隐藏和恢复，根目录不丢失；搜索期间禁用批量折叠   |
| 章节高亮       | 点击第三层条目，或跳到第 500 页           | 页码改变，当前章节高亮；点击定位按钮可滚动到对应项   |
| 侧栏保留       | 改宽度，横纵滚动，隐藏再打开              | 宽度、页签、折叠与滚动位置保留，不自动跳回当前章节   |
| 大目录         | 全部展开并滚动万项目录                    | 仅挂载视口附近约数十行，不挂载全部条目，滚动后不空白 |
| 阅读恢复       | 设置第 500 页、175%，关闭后重新打开       | 恢复第 500 页和 175%；切到文档 B 不继承 A 的记录     |
| 真实 PDF       | 切换真实样本，设第 12 页及 175%，关闭重开 | 正文画布正常，恢复页码/缩放；目录高亮 Chapter Two    |

PDF 翻页、缩放、旋转和全屏控件合并到最底部状态栏；确认仅有一条底栏、翻页可用，窄窗口控件可横向滚动。全屏时控件回到阅读器内部，退出后回到状态栏；本机 Chrome 的全屏请求受环境限制，尚未完成全屏交互验收。

聚焦页码输入框并输入 `22`，确认页码与两侧文字不被遮挡：紧凑底栏控件高度为 24px，焦点环使用内侧描边，页码标签与输入框保持 6px 间距。整组控件在状态栏内垂直居中，输入框移除纵向内边距并以 22px 行高居中显示数字。2026-10-23 本机 Chrome 已验证计算样式及激活状态截图；通用文档样式后加载时也不能恢复为 30px 高度或外扩焦点环。

逻辑回归另外覆盖命名目标、页引用、越界目标、非页码顺序目录、万项目录、12000 层目录、记录淘汰、损坏记录保护及存储拒绝。

真实样本搜索 `regression` 并切到 75%：第一页当前命中与第二页普通命中的原文字形都应清晰可读。2026-10-23 本机 Chrome 已验证；高亮使用半透明背景（普通命中 28%、当前命中 38%），不能使用不透明色块覆盖下层画布原文。

## 本次验证边界

2026-10-23：本机 Chrome 隔离模式验证搜索父级路径、全部展开/折叠、26px 行高、约 30 行挂载、章节跳转与高亮；侧栏隐藏/重开前后宽度及双向偏移一致。第 500 页/175% 关闭重开恢复，文档 B 从第一页与适应宽度开始。真实 PDF.js 样本验证画布显示、目录页目标、Chapter Two 高亮及第 12 页/175% 关闭重开恢复。

这些结果不等同于用户原始 PDF、真实 SSH 服务器、所有 PDF 编码、WebView2 或其他平台验收。关闭整个应用后的恢复依赖 WebView localStorage 可用，不恢复页内精确偏移或旋转角度。
