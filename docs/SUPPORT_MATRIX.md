# TermRill 功能支持矩阵

更新：2026-10-23。当前为内部试用版；已实现不等于所有系统和真实服务器均已验收。

| 功能     | 当前支持                                                                        | 限制或未验收项目                                                     |
| -------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| SSH      | 直连、标准跳板、密码、私钥、Agent、交互认证及主机指纹确认                       | 厂商专用堡垒机未实现；认证与服务器组合仍需独立验收                   |
| 凭据     | 用户主动选择系统凭据库，配置不保存密码                                          | macOS/Linux 凭据库与发行包未完成独立验收                             |
| 会话     | 多标签、独立目录和终端、后台传输                                                | 重启不自动恢复已认证会话                                             |
| 导航     | 本地/远程收藏、最近目录、返回/前进                                              | 收藏和最近存本机 WebView，历史仅当前工作区；无云同步                 |
| 布局     | 左右面板和终端尺寸可调、键盘操作、恢复默认                                      | 有尺寸范围及视口限制；更多 DPI/屏幕尺寸仍需验收                      |
| 命令面板 | 搜索并调用现有界面动作，搜索聚焦快捷键                                          | 不执行任意 Shell，终端/编辑器输入不接管                              |
| 文件管理 | 分页浏览、当前目录名称搜索、创建、删除、单项/批量重命名、远程 rwx 权限          | 批量仅 2～100 个普通文件；无 ACL、回收站及递归内容搜索               |
| 传输     | 文件/目录上传下载、暂停、取消、续传、并发、限速                                 | 真实网络吞吐仍取决于直连/中继、延迟及丢包，不保证跑满带宽            |
| 恢复     | 原配置任务恢复、重新认证后恢复选中任务                                          | 无后台自动重连，有其他未结束任务时禁止通过恢复入口重连               |
| 覆盖保护 | 临时文件、源核对、安装和失败恢复                                                | SFTP 检查与安装非通用事务，不能检测所有同大小同时间并发改写          |
| 文本     | 多编码、有限大小编辑、大文件分段只读、保存冲突检查                              | 无外部编辑器联动；编码启发式可能误判；只读文本差异由目录同步入口提供 |
| 预览     | Markdown、Mermaid、Notebook、图片、PDF、CSV/TSV；PDF 目录搜索/当前章节/阅读恢复 | Notebook 不执行，PDF 不做 OCR；资源与结果数量有限制                  |
| ZIP      | 列表、预览、校验、解压、创建与修改                                              | 可选 AES-256 内容加密；分卷不支持；资源受限                          |
| TAR/7Z   | TAR 系列、7Z 读取、预览、校验、解压、创建和增删重建                             | 非 ZIP 展开/中间包限 512 MiB；元数据标准化；7Z 可选加密文件名        |
| 只读归档 | RAR 和单文件 GZ/BZ2/XZ 读取、预览、校验和解压                                   | 不创建或修改；RAR 分卷不支持，固实包可能需顺序展开                   |
| 同步     | 单向规则与排除项、快速/严格比较、文本差异、任务级结果报告、选择同步和取消       | 报告仅当前会话；双向合并及定时同步未实现，真实服务器验收待完成       |
| 终端     | PTY 输入、尺寸适配、多标签、分屏、缓存搜索及有界日志追踪                        | 终端已由用户实测；日志轮转与平台组合仍需持续验收                     |
| 工作台   | Linux CPU/内存/根分区手动采集；连接分组；白名单配置交换；常用命令确认执行       | 状态仅 Linux；命令无交互、有时间/输出上限；真实服务器组合待验收      |
| 诊断     | 错误分类、脱敏摘要、分阶段性能日志                                              | 文本匹配只作建议，完整性能/兼容基线未验收                            |
| 发行     | Windows NSIS 脚本；Actions 手动构建 Windows、macOS 双架构、Linux 测试包配置     | 托管多平台打包、最新版安装升级、签名/自动更新及多平台验收未完成      |
| 长期扩展 | 已有需求规划                                                                    | AI、团队、插件、计划任务和远程互传未实现                             |

## 验证边界

2026-10-23，移除旧品牌兼容层后的代码通过格式检查、前端生产构建、60 项 Node 回归、Rust 离线检查、Clippy 全目标检查及 140 项本机 SSH fixture 回归。统一入口已完整验证；最新上传修复分项复核，含 6 项版本/入口阻断、3 项提交诊断与 4 项上传收尾故障回归；Windows CI 已配置，GitHub 托管运行仍待验证。

以上证明所覆盖的 Windows 本机逻辑及故障服务用例通过，不代表真实服务器、系统凭据库实机行为、安装升级或 macOS/Linux 已完成验收。PDF 的目录、搜索和底栏已有本机 Chrome 交互验证，全屏及更多 DPI/窗口组合仍需验收。

操作及资源限制见 [使用指南](USAGE.md)，最新证据和历史记录见 [验收记录](READINESS.md)。
