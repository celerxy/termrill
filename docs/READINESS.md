### v0.4.0 回环下载性能工具（2026-10-24）

新增显式基准入口：当前 russh 原生握手与生产下载流程对比系统 OpenSSH SFTP，交替顺序、逐次核对长度和 SHA256，并导出白名单数值报告。Windows PowerShell 入口实测 8 MiB、2 轮、TermRill 并发设置 1 和 3，共 8 次下载全部核验一致；报告标记 `russh-native-download` 和 `loopback-only`。早期使用旧测试入口的样本已标为废弃，不作为当前实现的性能证据。

独立运行 9 项 Python 工具测试通过，覆盖摘要与长度、数值字段白名单、报告防覆盖、低磁盘空间、进程超时、启动失败和清理边界。最终原生代码的 153 项 Rust 检查通过；性能入口在普通回归中不自动采样，采样另由前述命令验证。版本与格式检查、cargo check 及全目标 Clippy（`-D warnings`）通过。回归数据使用独立临时目录，基准编译仅在子进程关闭增量缓存，避免大体积缓存影响采样准备。

本机 Windows debug 数据只证明工具链路和完整性，不代表 release、macOS/Linux、跨境线路或真实 TUN 的吞吐。真实服务器尚未接入自动入口；场景标签不验证实际路由，未据此调整生产连接数、读取窗口或恢复策略。该工具已随 v0.4.0 提交并发布；实机吞吐仍未验收。
