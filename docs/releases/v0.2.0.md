# TermRill v0.2.0 Preview

## New

- Read EPUB 2/3 books from local files, remote files and archive previews. Navigate chapters and internal links, adjust font size and display book images.
- Resize the EPUB table of contents, keep long titles on one line, and scroll horizontally with the arrow buttons, touchpad or Shift + wheel. Only the current destination is highlighted.
- macOS builds now use free ad-hoc signing before DMG creation. CI verifies both the built app and the copy inside the DMG, including signature validity, architecture, executable UUID and matching binary hashes.
- Windows setup now uses TermRill artwork, application icons, clearer fonts and shorter bilingual welcome text.

## Downloads

Windows x64: `.exe`; macOS Apple Silicon and Intel: separate `.dmg` files; Linux x64: `.deb` and `.AppImage`. Each of the five installers includes a matching SHA256 file.

## Validation and limitations

All platform packaging jobs must pass before this Release is published. Release assets are checked against the originating Actions artifacts and their installer checksums before upload; uploaded digests are verified before the draft becomes public.

This is a preview. macOS ad-hoc signing is not Developer ID signing or notarization, and does not guarantee stable local-network permission identity across updates. Windows installers are unsigned. Platform installation, upgrade and real-server compatibility still need practical validation; build success does not establish runtime compatibility with every system.

EPUB previews are read-only, use sanitized reflowable XHTML, and do not load scripts or external resources. Original styles, embedded fonts, DRM, font obfuscation, audio/video and fixed layouts are not supported. The existing 32 MiB preview limit applies, with additional per-resource and expansion limits.
