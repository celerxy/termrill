# TermRill v0.3.0 Preview

## Added

- Distinguish unreachable hosts, DNS resolution failures, refused connections, timeouts, and SSH negotiation failures with specific troubleshooting guidance.
- Show when transfer progress bytes stop changing or progress events become stale. Hide outdated speed and remaining-time estimates.
- Preview and copy a transfer observation snapshot containing only fixed descriptions and numerical progress samples.

## Improved

- Preserve manual reconnect and resume actions for the more specific network error categories.
- Keep SSH authentication rejection separate from file permission failures.
- Include the Windows installer and uninstaller styling improvements prepared in v0.2.1.

Diagnostics describe client observations and do not establish a proxy, route, server, or disk bottleneck. Paused and completed tasks do not trigger byte-progress waiting warnings. No automatic retries, network changes, or changes to host-key verification are introduced.

This is a preview. Installation, upgrades, real-server performance, and platform-specific behavior require further acceptance testing. macOS builds use ad-hoc signing without Developer ID signing or notarization.
