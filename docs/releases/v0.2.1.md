# TermRill v0.2.1 Preview

## Fixed

- Apply the TermRill header explicitly to Windows uninstaller pages.
- Align installation and uninstallation progress colors and detail-list typography with the application branding.
- Collapse file-operation details by default while keeping the Show details control available.

This preview retains the EPUB reader and macOS ad-hoc signing introduced in v0.2.0. macOS builds are not Developer ID signed or notarized.

Installers and their SHA256 files are published only after the complete release workflow succeeds. Interface previews do not replace real installation, upgrade, or uninstallation checks.
