# TermRill v0.5.3 Preview

- Reduce the terminal toolbar from 44px to 32px and replace filled active tabs with a thin violet underline.
- Keep terminal actions in a single row at narrow window widths, with horizontal scrolling confined to the tab list.
- Reveal the selected terminal tab after adding or switching sessions without moving keyboard focus or recreating SSH channels.

Existing log, search, split, expand, and close actions remain available. Component preview checks do not replace native desktop or SSH protocol acceptance.
