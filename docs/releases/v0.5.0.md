# TermRill v0.5.0 Preview

- Remember EPUB chapters, relative reading positions, and font sizes locally using content fingerprints without storing names, paths, or book content.
- Explain manual transfer recovery requirements and prevent unavailable reconnect actions while other tasks remain active.
- Check local free space before native file downloads, counting only remaining bytes when resuming and preserving existing data on insufficient capacity.
- Add actionable storage and EPUB validation diagnostics, and refresh release status and installation acceptance guidance.

Space checks do not reserve capacity or measure remote quotas. Real-server performance, sleep/force-quit recovery, and cross-platform installation acceptance remain separate checks. This release does not add automatic reconnection or bypass host verification.
