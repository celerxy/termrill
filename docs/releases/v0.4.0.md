# TermRill v0.4.0 Preview

## Developer tooling

- Add an opt-in loopback download comparison between the production TermRill transfer pipeline and system OpenSSH SFTP.
- Alternate client order, verify every downloaded file by length and SHA256, and export numerical samples and median throughput.
- Keep test keys, source data, downloads, and raw logs out of the public repository. Bind both clients to the fixture's expected host key.

This tooling does not change application transfer settings or networking. Scenario labels are user supplied; loopback results do not measure VPN or WAN throughput. Debug smoke tests validate the tool, not release performance. Real-server and platform-specific acceptance remain separate.
